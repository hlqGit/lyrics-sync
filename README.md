# Lyrics

A floating macOS window that shows synced lyrics for whatever is playing in Apple Music, Spotify or YouTube, with media controls, an Apple Music-style full-screen mode, and a sync editor for publishing lyrics to [LRCLIB](https://lrclib.net).

**Install** (Apple Silicon, macOS 14+): download `Lyrics.zip` from [Releases](../../releases), unzip, move `Lyrics.app` to Applications. The app isn't notarized, so the first time, right-click → Open (or System Settings → Privacy & Security → Open Anyway). Allow the prompts to control Music/Spotify/your browser.

**YouTube:** in Chrome enable View → Developer → Allow JavaScript from Apple Events (Safari: Develop menu, same option).

**Build from source:** `./build.sh`

> Generative AI was used in the design process and this app may be subject to issues or bugs.
